# Stella Chart

GitHub Pagesで公開できる、依存関係なしの静的ホロスコープWebアプリです。

## 公開方法

1. このフォルダの内容をGitHubリポジトリのルートへ配置します。
2. GitHubの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、`main` ブランチの `/ (root)` を指定します。

## 現在の機能

- 生年月日・出生時刻・出生地の入力
- 太陽星座の判定と簡易リーディング
- SVGによる出生図風チャート表示
- モバイル対応

※天体の正確な度数・ハウス・アスペクトを計算する場合は、次の段階で天文計算ライブラリを追加できます。
